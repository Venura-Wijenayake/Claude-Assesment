# Spoke: Daily Sweep

Paste `BRIEF.md` first, then this.

---

**LANE: Daily job sweep.**

Find me every job posted in the last 3 days that I should consider. Search actively — don't work
from memory.

**Target titles** (anything in this space, don't be rigid about exact wording):
- IT Specialist / IT Technician / Desktop Support / Help Desk Tier 2–3 / Tech Support Specialist
- Technical Operations / Systems Support / Jr Systems Administrator
- Data Analyst / Reporting Analyst / Business Analyst / Data Technician
- QA Analyst / QA Tester
- Junior Software Developer / Application Support

**Where to look** (Sacramento metro + remote):
- Indeed, LinkedIn, ZipRecruiter, Glassdoor
- **EDJOIN** — school districts (I already work in one; district IT hires constantly)
- Health systems: UC Davis Health, Sutter, Kaiser, Dignity
- Staffing firms: Robert Half, TEKsystems, Insight Global, Robert Walters, Aerotek
- CalCareers / county + city of Sacramento job boards
- Local MSPs and mid-size employers

**Hard filters — drop anything that fails these:**
- Full-time (or contract-to-hire that converts). No part-time.
- Pay clearly above $25/hr, or a range that plausibly clears it. **Flag unlisted pay.**
- No sponsorship needed — I'm a permanent resident, so this is never a blocker, but skip
  clearance-required roles.
- **Transit-accessible in Sacramento, OR remote/hybrid, OR single-site.** I have a learner's
  permit and legally cannot drive alone — drop multi-site/field-tech roles requiring a license
  and personal vehicle. If a posting requires a valid driver's license, flag it rather than
  silently dropping it.

**Output format** — a table, ranked best-fit first:

| Role | Employer | Pay | Location / mode | Why me | Risk | Link |

Then, below the table:
- **Top 3 to apply to today**, with a one-line reason each
- Anything with a **warm angle** (someone I could contact, a staffing firm I'm already
  onboarded with, a district I already work for) — call these out separately, they're highest value
- Anything I should skip and why, so I can push back if you got it wrong

**Rules:** don't pad the list. Five real fits beats thirty maybes. If it's a thin day, say so.
Never invent a posting or a pay figure — if you can't verify it, say "unlisted."
