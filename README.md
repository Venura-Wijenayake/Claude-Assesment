## The honesty machine (why this workspace exists)

You said it plainly: *never fabricate — I need proof I can actually defend.* So the system is:

```
claims-to-earn.md  ──(do the work, measure it)──>  facts.md  ──>  résumé / interview
       ▲                                                              
       └── anything you WISH you could say lives here until it's literally true
```

If a claim can't be traced to `facts.md`, **it doesn't get made.** That's not a limitation — it's what
lets you walk into a room and defend every line without flinching.

## Reality checks worth keeping in view

- **A CS degree is table-stakes in 2026, not a differentiator.** Portfolios were the **#1 hiring
  criterion (38%)** in a 2025 survey of 200+ engineering leaders — above internships. Your instinct
  about proof was right.
- **Junior SWE is a medium-term goal**, not next month's paycheck. **Data analyst** is the more
  attainable technical target (entry ~$25–35/hr, SQL is the main gap).
- **Be honestly small.** *"Piloted with 8 job-seekers over 2 weeks"* beats a vague *"used by many"* —
  it's specific, checkable, and proves you can get software in front of humans.
- **Sideways beats frontal.** Get into an org via IT/Tech Ops, build internal tooling, pivot
  internally — that route skips the brutal external junior screen entirely.
