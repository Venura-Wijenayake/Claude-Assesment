# Feedback Log

Every piece of real feedback from a real person. Dated, attributed, verbatim where possible.

**This file is portfolio material.** It's evidence that humans engaged with your work — and it's
where "iterated based on user feedback" stops being a claim and becomes a documented fact.

**Log everything:** launch-thread comments (Show HN / Product Hunt / Reddit are public and
timestamped), emails, DMs, form submissions, hallway comments from coworkers.

---

## How to use this

When someone gives feedback, add a row. When you **ship a change because of it**, fill in
`Change shipped` and link the commit. That link is the whole story: *user said → you shipped.*

## Running tally (keep honest)

Update as real numbers come in — these are the figures that graduate to `profile/facts.md`.

- **Job Radar** — real users: `0` · returning users: `0` · feedback items: `0` · changes shipped from feedback: `0`
- **Lighthouse Open Health** — real users: `0` · GitHub stars: `0` · open issues from others: `0` · changes shipped from feedback: `0`

> Rule: a user is someone **who isn't you and isn't family**, who used the tool for a real purpose.
> Count honestly — an inflated number here poisons every claim downstream.
